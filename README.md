## GitHub Pages
1. Upload all files and folders to the root of your GitHub repository.
2. Go to Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

## Logo
Replace the temporary `MH` logo box in the HTML with your official logo, or add your supplied logo as:
`assets/images/makaneta-logo.jpeg`
Then update the brand markup in the pages to use the image.

## Images
Add your real business, Internet Café, training, printing, photography and 360° photos to `assets/images/`. The gallery currently uses clean placeholders so the site works immediately without inventing business imagery.
